# ADR-006：[4] 移除空章節（R7）

- **日期**：2026-10-23
- **狀態**：Accepted
- **影響階段**：[4] 清理（`src/clean_pages.py`）
- **前提**：ADR-002（R4a 整行標籤刪除）、ADR-004（標題結構與 R6）
- **替代方案**：由 [5] 切分時略過空章節、保留原樣

## 1. 背景

ADR-004 讓 cleaned MD 帶有 `##`／`###`，[5] 以 `##` 章節作為 parent（ADR-005）。R4a 刪除配方標籤後，如果某個章節底下原本只有標籤，就會只剩一行標題、沒有任何內容。

實測（2026-10-23）：119 頁中共 1 例，`items-blocks-machines/certus_quartz_crystal` 的 `## Some Alternate Recipes`。它底下原本是 `Crafting (Shapeless)`、`Throw in Water` 兩行標籤。

## 2. 決策

依「各階段職責固定」的原則，空章節是去噪後的殘留，屬於 [4] 的職責；[5] 只負責切分，不處理資料品質。

- 新增 **R7 空章節移除**，順序為 R6 → **R7** → 空 body 守衛。
- 判定：標題的範圍到下一個同層或更高層的標題為止；範圍內沒有任何非空白的非標題行 → 刪除該標題。
- 由深到淺反覆判定：只含空子章節的章節也一併刪除。
- 被刪除的標題列入 `reports/cleaning_report.md`。

## 3. 否決方案

- **由 [5] 略過**：會讓 [5] 承擔資料清理，越過階段邊界；cleaned MD 也會留下不完整的結構。
- **保留原樣**：[5] 會產生只有標題、沒有內容的 parent，對檢索沒有幫助。

## 4. 驗證結果（2026-10-23）

| 檢查 | 結果 |
| --- | --- |
| 與變更前的 cleaned MD 比對 | 只有 `certus_quartz_crystal.md` 少了 `## Some Alternate Recipes` 一行 |
| 對帳 | 輸出 119 + 跳過 2 = 121 |
| 空章節殘留 | 0 |
| 純刪除檢查 | 通過 |
| 冪等 | 連跑兩次，輸出位元組相同 |

## 5. 後果

- cleaned MD 的每個標題底下都有內容，[5] 可以直接把每個 `##` 章節當成 parent。
- 「某物品有替代配方」這類資訊原本就只存在於配方圖片中；刪除空標題後，知識庫裡不再出現這個沒有內容的線索。
