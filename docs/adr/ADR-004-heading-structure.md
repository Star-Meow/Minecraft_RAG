# ADR-004：保留頁內標題結構（[3] 標記、[4] 正規化）

- **日期**：2026-10-22
- **狀態**：Accepted
- **影響階段**：[3] 抽取（`src/extract_pages.py`）、[4] 清理（`src/clean_pages.py`）；下游 [5] 據此做子母分層切分
- **部分取代**：ADR-002 §3「不處理：標題還原（`##`）」與 §7.1「`section` 恆為空」
- **替代方案**：[3] 改用 trafilatura markdown 輸出、改用其他 HTML→Markdown 套件、[4] 以啟發式猜測標題、在 [4] 依 [3] 提供的標題清單補記號

## 1. 背景

[5] 改採子母分層（parent = 章節、child = 章節內片段）後，需要頁內標題結構。現況：

- trafilatura json 模式不保留標題記號：extracted `text` 121 頁、cleaned MD 119 頁中，除頁首 H1 外沒有任何 `##`／`###`。
- raw HTML 的 `<article>` 仍保有結構：124 頁中 113 頁含 h2／h3（h1 153、h2 262、h3 24）；11 頁有多個 H1（例：`terminals` 每個子終端各一個 H1），且配方區塊標題 `Recipe`／`Recipes` 本身是 h2。

## 2. 實測（2026-10-22）

扣掉每頁第一個 H1 後的 310 個小標題中：

| 類別 | 數量 | 對應到 trafilatura `text` 完全相同的行 |
| --- | --- | --- |
| `Recipe`／`Recipes`（配方標籤） | 82 | 屬噪音，由 [4] R4a 刪除 |
| 其他小標題 | 228 | **228/228 依序對應成功**（13 個重複文字，如 `The UI` ×4，依出現順序對應） |

整頁黏成單行的 19 頁沒有非標籤小標題，不受影響。

## 3. 決策

**職責分配**：只有 [3] 看得到 HTML，故由 [3] 辨識結構；[4] 只做去噪與正規化；[5] 只依 cleaned MD 已有的標題切分。

**[3]**：新增欄位 `markdown`。

1. `text` 保留 trafilatura 原值不異動。
2. 讀 `<article>` 的 h1–h3（`get_text(" ", strip=True)`），依文件順序以游標往下找 `text` 中去前後空白後完全相同的行，加上 `'#' × level + ' '` 前綴；找不到的標題不移動游標，記入 `reports/extraction_report.md`。
3. 層級照 HTML 原樣，不正規化、不判斷噪音。

**[4]**：輸入改讀 `markdown`。

1. 所有規則以「去掉標題記號後的行內容」比對：R1 會刪除 `# <title>`；R4a 會刪除 `## Recipe` 等標籤標題。
2. R2 門檻與字元統計以去掉記號的純文字計算，維持 ADR-002 的校準基準。
3. 新增 **R6 標題層級正規化**（R4b 之後、空 body 守衛之前）。以堆疊追蹤祖先標題，輸出層級 = 2 + 祖先數：
   - 一般頁：h2 → `##`，其下 h3 → `###`。
   - 多 H1 頁：頁內 H1 → `##`，其下 H2 → `###`；直屬頁面標題的 H2 仍為 `##`。
   - 每頁只保留 [4] 寫入的 `# <title>`。

## 4. 否決方案

- **[3] 改 `output_format="markdown"`**：已由 ADR-002 §5 否決（24 頁無 H1、17 頁多 H1、`Recipe` 被升為 `## Recipe`，且不修復黏合與標籤）。
- **其他 HTML→Markdown 套件**（markdownify、html2text、unstructured、docling）：屬新依賴（AGENTS §8），而且要重新校準 ADR-002 的全部規則；本方案不新增依賴，對應率 228/228。
- **[4] 啟發式猜標題**（短行、無句號、後接句子）：會誤判合法短行，ADR-002 盤點已證實裸短行語意不可單憑文字判定。
- **[3] 只輸出標題清單、由 [4] 補記號**：[3] 會輸出兩份要互相對照的資料，[4] 也必須知道 trafilatura 的換行行為；違反單一職責。

## 5. 驗證結果（2026-10-22）

| 檢查 | 結果 |
| --- | --- |
| [3] `title`／`text`／`source`／`hostname`／`http_status` 與變更前比對 | 121 頁全數相同 |
| [3] `markdown` 去掉記號後逐行等於 `text` | 121 頁通過 |
| [3] 標題對應 | matched 373、unmatched 58（21 個黏合頁的頁首 H1，由 R1-B 處理；37 個 `Recipe`／`Recipes`）；非標籤小標題 228/228 |

| [4] 對帳 | 輸出 119 + 跳過 2 = 輸入 121；例外 0 |
| [4] 去掉 `##`～`######` 記號後與變更前的 cleaned MD 比對 | 119 頁位元組相同（規則效果不變） |
| [4] 結構 | 每頁恰一個 `#`；標籤標題殘留 0；層級跳級 0；70 頁含小標題，`##` 188、`###` 40 |
| [4] 冪等 | 連跑兩次，輸出位元組相同 |

## 6. 後果

1. cleaned MD 正文帶 `##`／`###`；[5] 的 `section` 不再恆空，可作為 parent 邊界。
2. Extracted JSON 新增 `markdown` 欄位（AGENTS §7 原「不加欄位」改為允許此欄）；BeautifulSoup 在 [3] 的用途擴大為「連結密度 + 標題結構」，仍不用於導覽發現。
3. [3] 對應不到的標題不會出現在輸出；站方改版時須檢查報告中的 unmatched 數。
4. ADR-002 的純刪除檢查改為：輸出每一行去掉標題記號後，等於某個輸入行（或其子字串）。
